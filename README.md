# Desenvolvimento Web 2

Bem-vindos ao repositório central da disciplina **Desenvolvimento Web 2**. Este espaço foi projetado para ser o ponto de encontro entre a teoria e a prática, onde transformamos lógica e JavaScript em aplicações web funcionais.

## o que é README?

este arquivo foi escrito em **Markdown**, uma linguagem de marcação leve que voce usará constantemente em sua carreira para documentar projetos, criar wikis no Github e estruturar mensagens técnicas.

> Dica de Markdown: voce pode criar citações com esta usando o caracter >.

## Benefícios desta Disciplina

a materia de Desenvolvimento Web 2 é o coração da formação de um desenvolvedor, Aqui, os beneficios vão além da escrita do código:

1. **Resolução de problemas complexos:** Voce aprenderá a decompor grandes desafios em pequenas tarefas tratáveis.
2. **Mentalidade mão na massa:** A disciplina foca na experimentação. O erro aqui não é um fracasso, mas um passo necessário para ao aprendizado.
3. **Domínio do JavaScript:** Foco total na linguagem que move a web moderna, desde a manipulação de DOM até a lógica de programação.
